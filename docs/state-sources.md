## Notes

- MO: RSMo 167.031 no longer holds the home-school hours; SB 727 (2024) moved them to RSMo 167.012 (effective Aug 28, 2025).
- NY: 900/990 hours and 180-day equivalency confirmed via NYC DOE (official district) documents quoting 8 NYCRR 100.10(f); nysed.gov regulation page itself returned redirect errors.
- NH: RSA 193-A:6 statute page shows repeal effective July 1, 2026; the chapter index still lists it. Confirm before shipping.
- KY: home schools follow the public-school term (KRS 158.080); 185 days / 1,062 hours come from KRS 158.070 definitions.
- WV: 180 days comes from W. Va. Code 18-5-45, referenced by 18-8-1(c).
- WA: 1,000 hours is a school-wide average for grades 1-12 (450 for K) via RCW 28A.195.010, referenced by 28A.225.010(4).
- NE: JSON requiredHours uses the secondary figure (1,080); elementary is 1,032. RI hours figure is RIDE's statement of the public-school equivalent, not a homeschool-specific statute number.
- Unverified (official pages blocked or statute text not retrievable): AL, AK, KS, MS, NH.
- Retrieval date for all rows: 2026-09-09.
